# SiliconComparision

Silicon-level studies of the STITCH NoC designs. Each study lives in its own folder.

## latch_study/

Latch versus no-latch comparison on the 2x2 and 3x3 meshes and the MPSoC.

- `A_original`: the hand-written design as received. Yosys aborts on it.
- `A1_original_synthesisable`: A with only `register_1bit` replaced, so it synthesises. Keeps the inferred latches
  (mesh2x2: 2,880 latch cells).
- `B_repaired_golden`: latch leaves replaced with the golden Phase 3 repairs.
- `C_repaired_stitch`: latch leaves replaced with the STITCH-repaired leaves.
- `leaves/`: defective, golden and STITCH-repaired source for each Phase 3 leaf.
- `scripts/run_yosys_stat.sh <design-dir>`: Yosys cell and latch counts. `scripts/build_manifest.py`
  regenerates `MANIFEST.md`.
- `COWORKER_BRIEF.md`, `PPA_SUMMARY.md`, `MANIFEST.md`: brief, PPA results and file inventory with SHA-256.
- `stitch_noc_analysis_bundle/` is local-only (gitignored).

## llm_oneshot_vs_stitch/

LLM one-shot generation versus STITCH on the 2x2 mesh (OpenROAD path). The golden reference is the hand-written
2x2 hierarchy rooted at `top_2x2_router`.

- `golden/handwritten`, `golden/A1`: copies of `latch_study/A_original/mesh2x2` and
  `latch_study/A1_original_synthesisable/mesh2x2`.
- `golden/reference`: the functional reference. It is golden/handwritten with only `register_1bit`,
  `register_4bit` and `register_32bit` replaced by their `phase3/tasks/<m>/golden.v`, built by
  `pipeline/build_reference.py`. Module for module it equals `latch_study/B_repaired_golden/mesh2x2` except for
  two added declarations (`wire rd_en_out` in ip_chnl, `wire mux_out3` in allot_vc). The hand-written files use
  those nets before their implicit declaration; Yosys accepts that, but Icarus (`iverilog -g2012`) does not.
- PPA references: A1 (`latch_study/A1_original_synthesisable/mesh2x2`) is the primary reference, the
  hand-written design as it ships. B (`latch_study/B_repaired_golden/mesh2x2`) is the like-for-like
  reference with the same three registers repaired.
- `modules.csv`: module inventory of the golden hierarchy, generated by `pipeline/inventory.py`.
- `specs/`: one behavioural spec per module.
- `tasks/<m>/`: Phase 3 task format (spec.md, tb.v, tb_signoff.v, golden.v, input.v, meta.json; parents also
  have lib/ and stubs/), built by `pipeline/make_tasks.py` and validated by `pipeline/check_tasks.py`
  (`reports/TASK_VALIDATION.md`).
- `pipeline/`: `oneshot_gen.py` (one-shot generation), `run_arms.py` (Phase 3 runner via `p3_bridge.py`:
  baseline = simloop, sem_esc_restart_v3 = stitch), `summarize.py`, `gate.py`, `prove_prompt_format.py`,
  `e2e_mock.py`, and the cluster files `hpc_env.sh`, `gen_job.slurm`, `deploy_gen.ps1`, `HPC_RUN.md`.
- `prompts/`, `outputs/{oneshot,simloop,stitch}/`, `assembled/`, `reports/`: study outputs.
- `runs/` is local-only (gitignored).
