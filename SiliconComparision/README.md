# SiliconComparision

Silicon-level studies of the STITCH NoC designs. Each study lives in its own folder.

## latch_study/

Latch versus no-latch comparison on the 2x2 and 3x3 meshes and the MPSoC.

- `A_original`: the hand-written design as received. Yosys aborts on it.
- `A1_original_synthesisable`: A with only `register_1bit` replaced, so it synthesises. Keeps the inferred latches
  (mesh2x2: 2,880 latch cells).
- `B_repaired_golden`: latch leaves replaced with the golden Phase 3 repairs.
- `C_repaired_stitch`: latch leaves replaced with the STITCH-repaired leaves.
- `leaves/`: defective, golden and STITCH-repaired source for each Phase 3 leaf.
- `scripts/run_yosys_stat.sh <design-dir>`: Yosys cell and latch counts. `scripts/build_manifest.py`
  regenerates `MANIFEST.md`.
- `COWORKER_BRIEF.md`, `PPA_SUMMARY.md`, `MANIFEST.md`: brief, PPA results and file inventory with SHA-256.
- `stitch_noc_analysis_bundle/` is local-only (gitignored).

## llm_oneshot_vs_stitch/

LLM one-shot generation versus STITCH on the 2x2 mesh (OpenROAD path). The golden reference is the hand-written
2x2 hierarchy rooted at `top_2x2_router`.

- `golden/handwritten`, `golden/A1`: copies of `latch_study/A_original/mesh2x2` and
  `latch_study/A1_original_synthesisable/mesh2x2`.
- `modules.csv`: module inventory of the golden hierarchy, generated by `pipeline/inventory.py`.
- `specs/`: one behavioural spec per module.
- `tasks/`, `prompts/`, `pipeline/`, `outputs/{oneshot,simloop,stitch}/`, `assembled/`, `reports/`: study stages.
- `runs/` is local-only (gitignored).
