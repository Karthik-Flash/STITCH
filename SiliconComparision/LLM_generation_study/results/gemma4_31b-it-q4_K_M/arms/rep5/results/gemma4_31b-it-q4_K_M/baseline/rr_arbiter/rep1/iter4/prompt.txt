SPECIFICATION:
# rr_arbiter

## Behaviour

Round-robin arbiter for 4 requesters, numbered 0 to 3. Requester i asks for a grant when `req[i]` = 1.

The arbiter remembers the number of the requester it granted last (the "last" requester). The grant is
combinational, from `req` and the last requester:

- `gnt` is one-hot: `gnt[i]` = 1 means requester i is granted. `gnt` = 0 when no requester asks.
- Priority starts at the requester after the last one and goes round: if the last requester is L, the order
  is L+1, L+2, L+3, L (numbers taken modulo 4). The first requester in this order with `req` = 1 is granted.

The last requester changes only at a rising `clk` edge where `advance` = 1 and `gnt` is not 0: it becomes
the requester granted at that edge. Otherwise it keeps its value. `advance` = 1 with `gnt` = 0 changes nothing.

So a requester that keeps asking is granted within 4 edges with `advance` = 1 and a grant.

## Reset

Synchronous, active-high `reset`: at a rising `clk` edge with `reset` = 1 the last requester becomes 3, so
the priority order after reset is 0, 1, 2, 3. `advance` at that edge is ignored.

## Ports

5 ports, in this exact order:

```verilog
input clk;
input reset;
input [3:0] req;
input advance;
output [3:0] gnt;
```

Parameters: none.

## Children

None. This module instantiates no other module.

```verilog
module rr_arbiter (
    input clk,
    input reset,
    input [3:0] req,
    input advance,
    output [3:0] gnt
);

    reg [1:0] last;
    reg [3:0] gnt_comb;
    reg [1:0] gnt_idx;

    assign gnt = gnt_comb;

    // Combinational logic to determine the grant based on the last requester
    always @(*) begin
        case (last)
            2'b00: begin
                if (req[1]) 
                    gnt_comb = 4'b0010;
                else if (req[2]) 
                    gnt_comb = 4'b0100;
                else if (req[3]) 
                    gnt_comb = 4'b1000;
                else if (req[0]) 
                    gnt_comb = 4'b0001;
                else 
                    gnt_comb = 4'b0000;
            end
            2'b01: begin
                if (req[2]) 
                    gnt_comb = 4'b0100;
                else if (req[3]) 
                    gnt_comb = 4'b1000;
                else if (req[0]) 
                    gnt_comb = 4'b0001;
                else if (req[1]) 
                    gnt_comb = 4'b0010;
                else 
                    gnt_comb = 4'b0000;
            end
            2'b10: begin
                if (req[3]) 
                    gnt_comb = 4'b1000;
                else if (req[0]) 
                    gnt_comb = 4'b0001;
                else if (req[1]) 
                    gnt_comb = 4'b0010;
                else if (req[2]) 
                    gnt_comb = 4'b0100;
                else 
                    gnt_comb = 4'b0000;
            end
            2'b11: begin
                if (req[0]) 
                    gnt_comb = 4'b0001;
                else if (req[1]) 
                    gnt_comb = 4'b0010;
                else if (req[2]) 
                    gnt_comb = 4'b0100;
                else if (req[3]) 
                    gnt_comb = 4'b1000;
                else 
                    gnt_comb = 4'b0000;
            end
            default: begin
                gnt_comb = 4'b0000;
            end
        end
    end

    // Combinational logic to convert one-hot grant to index
    always @(*) begin
        case (gnt_comb)
            4'b0001: gnt_idx = 2'b00;
            4'b0010: gnt_idx = 2'b01;
            4'b0100: gnt_idx = 2'b10;
            4'b1000: gnt_idx = 2'b11;
            default: gnt_idx = 2'b00;
        end
    end

    // Sequential logic to update the last requester
    always @(posedge clk) begin
        if (reset) begin
            last <= 2'b11;
        end else if (advance && (gnt_comb != 4'b0000)) begin
            last <= gnt_idx;
        end else begin
            last <= last;
        end
    end

endmodule
```
