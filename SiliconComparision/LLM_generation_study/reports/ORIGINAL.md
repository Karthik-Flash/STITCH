Generated by `scripts/describe_original.py` from the files as downloaded (nothing in the folder is changed).

## What it is

- A Vivado 2014.4 project, part xc7z020clg484-1, board em.avnet.com:zed:part0:1.2 (ZedBoard).
- Original location recorded in the project file: `E:/P20170401/Bhanu_PhD_work/FPGA/FPGA_2x2_Mesh_verified_bitstream_backup/project_4on2014edition/project_4on2014edition.xpr`.
- Top `main` (`Main.v`): the 2x2 mesh `top_4_router` (four 5-port routers `top_module`, 4 virtual channels per port) with a VIO core driving the core inputs
  and an ILA core capturing them, for testing on the board.
- `NOC_4_ROUTER.v`: the simulation testbench (head, body and tail flits from router 1's core).
- `Outputs_2x2/`: 9 screenshots of the Vivado hardware manager with the bitstream on the board (`r1_r2`, `r1_r3`, `r1_r4` x head, payload, tail flit): VIO sets router 1's core input, the flit appears at
  the destination core output.
- `project_4on2014edition.runs/impl_3/main.bit`: the bitstream (Mon Apr 22 16:15:52 2019).
